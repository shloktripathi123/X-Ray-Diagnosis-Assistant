# X-Ray-Diagnosis-Assistant

**Live Demo:** https://x-ray-diagnostic-assistant.replit.app

An AI-powered application designed to make X-ray image interpretation faster, smarter, and more accessible.

## What It Does

This app uses artificial intelligence to analyze a user-provided X-ray image and classify it as **Healthy, Pneumonia, Tuberculosis, or COVID-19**. It features an intuitive interface, provides fast predictions, and demonstrates how modern machine learning can be applied to medical imaging. The project is intended for **educational and research purposes** and is not a substitute for professional medical diagnosis.
