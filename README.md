# X-Ray-Diagnosis-Assistant

**Live Demo:** https://replit-project--tripathiinbox.replit.app/

An AI-powered application designed to make interpretation and diagnosis using X-Ray images faster, smarter, and more accessible.

## What It Does

This app uses artificial intelligence to analyze a user provided image of an X-Ray and output a diagnosis between healthy, pneumonia, tuberculosis and COVID. It provides an intuitive interface, delivers fast and accurate results, and is built to create a seamless user experience. Whether you're exploring AI capabilities or solving real-world problems, the app demonstrates how modern machine learning can be integrated into a practical, user-friendly solution.
